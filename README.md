# Automatic Vehicle Entry and Smart Parking Assistance System 🚗🔐🅿️

This project automates vehicle entry using license plate recognition and assists in smart parking using sensors.

## 🔧 Technologies Used
- Raspberry Pi 4 (4GB)
- Python (OpenCV, NumPy)
- Ultrasonic Sensor, Servo Motor
- MySQL
- HTML/CSS (for optional dashboard)

## ⚙️ Features
- Automatic gate control for authorized vehicles
- Number Plate Detection using Image Processing
- Smart parking slot detection
- MySQL database for registered users
